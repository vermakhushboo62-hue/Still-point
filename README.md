# Still Point

A small calming tool. Pick what you're feeling (overwhelmed, anxious, afraid, angry, betrayed, jealous, small, unfocused, not enough, sad, lonely) and get a guided breathing pattern, a short movement and a simple mind reset.

Plain HTML, no build step. Installable on phones and works offline after the first visit.

Hosted on Cloudflare Pages: build command empty, output directory `/`.
